You wrote !keep.txt. Why is it still ignored?

With logs/ then !logs/keep.txt, the file stays ignored: git never looks inside an ignored directory, so the re-include does nothing. Swap the first line for logs/* and it works.

What it does

  • IGNORED or TRACKED per path, with the deciding line number
  • Last match wins, negation, directory-only rules, **, ranges and escapes
  • Explains the parent-directory trap
  • Matches real git check-ignore on thousands of random cases
